ALPER YAVUZ — PORTFOLIO V1
============================

Bu sürüm sıfırdan hazırlanmıştır.

TASARIM
- Tam siyah arka plan: #000000
- Kırık beyaz metin
- Küçük ve geri planda kalan Alper Yavuz logosu
- Alper: thin / Yavuz: bold
- Awwwards tarzı uzun, sinematik proje akışı
- Köşeli TR / EN anahtarı
- Masaüstü özel cursor
- Loading ekranı
- Scroll progress çizgisi
- Fullscreen menü
- Proje modalı
- Mobil uyumlu responsive yapı
- Reduced motion erişilebilirlik desteği

FONT
Kendi lisanslı Grotesk font dosyalarını aşağıdaki klasöre koy:

assets/fonts/Grotesk-Thin.woff2
assets/fonts/Grotesk-Regular.woff2
assets/fonts/Grotesk-Bold.woff2

Font dosyalarını koymadan da site Helvetica Neue / Arial ile çalışır.

PROJE GÖRSELLERİ
Şu an beş adet placeholder alan bulunuyor.
Daha sonra her .project__media alanına görsel veya video ekleyebiliriz.

TELEFONDA ÇALIŞTIRMA
1. Zip dosyasını aç.
2. Klasörü telefona kopyala.
3. Termux'ta klasöre gir:
   cd /klasor/yolu/alper-yavuz-portfolio-v1
4. Sunucuyu başlat:
   python -m http.server 8080
5. Aynı Wi-Fi'daki bilgisayardan:
   http://TELEFON_IP:8080

BİLGİ
TR / EN seçimi tarayıcıda kaydedilir.
